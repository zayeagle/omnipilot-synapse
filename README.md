# OmniPilot Synapse

Intelligent multi-domain knowledge management and governance — capture from WeChat and browser, systematically organize and govern personal knowledge, AI-distill key points, and spaced-review for retention. Pluggable storage: Git, self-hosted DB, or local files.

## What this is

A private **personal knowledge OS** (智囊袋) that closes the loop from capture → distill → place into a system → retrieve → spaced review.

**First-party clients (MVP):** WeChat Mini Program + Browser Extension.

**Storage (pluggable):** Git repository · self-hosted public DB/API · local filesystem.
